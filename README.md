# React Router Project

A simple React application demonstrating navigation between multiple pages using React Router DOM.

## Features

- Navigation between pages without reloading
- Dynamic routing using username
- Nested routing with a common layout
- Custom 404 error page
- Simple and user-friendly interface

## Technologies Used

- React.js
- React Router DOM
- JavaScript
- CSS

## Pages

| Page | Route |
|---|---|
| Home | `/` |
| About | `/about` |
| Projects | `/projects` |
| Contact | `/contact` |
| Login | `/login` |
| User Home | `/:username` |
| Error | `/*` |

## Installation

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the application:

   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173/` in your browser.

## About

This project was created to practice React Router concepts such as `createBrowserRouter`, `RouterProvider`, `Link`, nested routes, and dynamic URL parameters.
